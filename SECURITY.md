# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in **dot md**, please report it responsibly rather than opening a public issue.

Please send an email to:
**creativitywithsatyam@gmail.com**

Include:
- A description of the vulnerability and its potential impact.
- Steps or a proof of concept to reproduce the issue.
- Any suggestions for mitigation.

We will acknowledge receipt of your report within 48 hours and coordinate a fix before public disclosure.
